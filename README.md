# ImageAnalyzerAgent
Image Analyzer Agent
This bot is to explore the new preview feature in co-pilot related to image analysis and how we can use it in a real case senarios. This agent can be used to check the sentiment of the customers or check items scanned by an X-ray machine. This agent can be integrated with X-ray machines, where the machine sends images to the agent for analysis. The agent then evaluates the contents of the items in the image and takes appropriate actions if restricted items are detected. Also it can be integrated wth cameras to check the sentiment of customers.
